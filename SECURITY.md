# Security Policy

## Scope & Purpose

This repository is dedicated to low-level security research on UEFI firmware, TPM 2.0 measured boot architecture, and hardware-anchored trust boundaries. Research into firmware weaknesses is conducted to enhance defensive system assurance and identify architectural edge cases.

## Supported Versions

| Version | Supported |
| :--- | :--- |
| 1.0.x | Yes |
| < 1.0 | No |

## Reporting Security Vulnerabilities

If you discover a security vulnerability or critical defect in this project:

1. **Do not disclose the issue publicly** via GitHub Issues or public forums.
2. Submit a technical summary including steps to reproduce, affected firmware environments, and architecture analysis directly to:
   - **Contact**: Adam (`adam@networkconnect.org`)
   - **PGP / Keybase**: Available upon verified request.

## Vulnerability Handling SLA

- **Initial Acknowledgment**: Within 48 hours.
- **Triage & Reproduction**: Within 7 business days.
- **Remediation & Coordinated Disclosure**: 90-day responsible disclosure window following vendor or project patch readiness.
